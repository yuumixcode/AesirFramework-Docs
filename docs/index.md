# AesirFramework

> 面向 Unity / 团结引擎的渐进式 MVC 架构框架与功能模块集合。**极简、可渐进、面向实战。**

## 核心包

### Aesir Architecture

渐进式 MVC 架构框架 —— 能力接口组合、命令/查询模式、轻量事件(MiniEvent)与响应式属性(ObservableValue)。

- 六档渐进式示例:快捷 → 标准 → 严格(每个三档 MVC + 三档 MVP)
- 纯 C# 架构根 + MonoBehaviour 适配层

[开始使用](architecture/getting-started.md){ .md-button .md-button--primary }

### Aesir Modules

功能模块集 —— 轻量级 UI 框架(Manager-of-Managers 单例、四层 Canvas 层级、面板生命周期)与实验性事件模块。

[开始使用](modules/getting-started.md){ .md-button }
