# 支持

## 获取帮助

- **问题反馈与功能建议**:[GitHub Issues](https://github.com/yuumixcode/AesirFramework/issues) —— 提问时附 Unity / 团结引擎版本、包版本与复现步骤
- **源码仓库**:[yuumixcode/AesirFramework](https://github.com/yuumixcode/AesirFramework)(MIT)
- **作者**:yuumixcode(Runestone)

## 提问前自查

1. 版本是否为最新?(`Tools → Aesir → Check for Updates` 或 Package Manager 检查)
2. 是否踩中[高频陷阱](faq.md)?框架异常消息(fail-fast)大多已含修复指引
3. Odin / Addressables / Input System 相关问题请注明是否安装(可选项影响代码路径)

## 贡献

欢迎任何形式的贡献 —— Bug 报告、功能建议、文档改进、代码提交:

- 阅读主仓库 [CONTRIBUTING.md](https://github.com/yuumixcode/AesirFramework/blob/main/CONTRIBUTING.md) 了解提交流程
- 遵循 [CODE_OF_CONDUCT.md](https://github.com/yuumixcode/AesirFramework/blob/main/CODE_OF_CONDUCT.md)
- 推荐从 `main` 拉分支;提交信息遵循 Conventional Commits
- 文档问题(含本站点)可直接在 [AesirFramework-Docs](https://github.com/yuumixcode/AesirFramework-Docs) 提 PR —— 每页右侧有"编辑此页"入口

## 相关资源

- **Aesir Inspector** — 独立公开仓库,面向 Odin Inspector 开发者的学习工具包:[yuumixcode/AesirInspector](https://github.com/yuumixcode/AesirInspector)
- **Cysharp/ObservableCollections** — 高性能可观察集合库(MIT),Aesir Observable 家族的高级能力推荐直接使用
- **Eflatun.SceneReference** — 强类型场景引用方案(MIT),`SceneAssetWrapper` 的功能设计参考
